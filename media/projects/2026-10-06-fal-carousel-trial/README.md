# fal.ai carousel trial: "a new sibling"

A seven-slide Hebrew Instagram carousel for LumeBook (1080×1350), built to test whether fal.ai can be the image partner for a weekly carousel. The photographs are AI-generated by fal.ai (Nano Banana 2). Every word, the gold thread motif and the layout are added afterwards in HTML, so all copy stays editable and no text is ever generated inside an image.

Verdict and scores: [evaluation.md](evaluation.md). Exact prompts, seeds and cost: [prompts/generation-prompts.md](prompts/generation-prompts.md).

## How the direction was chosen

1. Two illustrated cover directions were compared first (pencil-and-gouache paper vs night-light). The paper one won and a full illustrated carousel was built. It is kept in `source/legacy-illustrated/`.
2. The user then asked for the look of the LumeBook website's characters. The site mixes glossy 3D-cartoon covers, warm photo-real tiles and a cartoon mascot, so four cheap drafts were made (`style-options.png`), then the two finalists on Nano Banana 2 (`style-options-2-3.png`).
3. The user chose **photo-real**, and waived the brief's rule against stock-photo and fake-photo looks. The final carousel is photo-real, with an "AI" label on slides 1 and 7. `model-comparison.png` shows the choice.

## Requirements

- Google Chrome (used headless for the export)
- Python 3 with Pillow and NumPy: `pip install pillow numpy`
- Only for new images: a fal.ai key exported as `FAL_KEY` in your shell profile, never in this folder

## Edit the words

1. Open `source/carousel.html`. Each slide is a `<section class="slide" data-n="…">` with its copy in `<div class="copy">`. Line breaks are explicit `<br>` tags, so you decide where each Hebrew line breaks. Text in `<span class="em">` is set in gold.
2. Open the file in Chrome to see all seven slides stacked; add `?s=3` to the address to see only slide 3 at full size.
3. Export from inside `media/projects/2026-10-06-fal-carousel-trial/`:

```bash
python3 source/render.py
```

`python3 source/render.py 3 5` re-exports only slides 3 and 5. The contact sheet and the 25% sheet are rebuilt each time.

## Regenerate or replace an image

1. Edit or add a job in `source/jobs.json`. A prompt is a list of block names (from `blocks`) joined in order. The slide jobs (`p1`, `p2`, `p4` to `p7`) list `"refs": ["style-2-nb2"]`, which uploads that photo and passes it to `fal-ai/nano-banana-2/edit` as the character reference.
2. Run it (about $0.08 and 15 seconds per image):

```bash
python3 source/fal_generate.py p5
```

The new PNG replaces `generated-assets/p5.png` and the call is appended to `generated-assets/generation-log.jsonl`. Rename the old file first if you want to keep it.

3. Place the art and export:

```bash
python3 source/prep_art.py && python3 source/render.py
```

In `prep_art.py`, `ART` maps each slide to its source image and `PUSH` moves a photo down (mirroring the plain wall above) so the headline clears the faces. `park()` repairs slide 4, whose original had a flat wall-coloured slab pasted over the sky: it finds the seam, keeps only the real photograph and fades it into cream.

`python3 source/fal_generate.py --list` shows every job with its endpoint and price. The script talks to `https://mcp.fal.ai/mcp`, the same server `claude mcp add fal-ai` registers, so it works even when the MCP tools are not loaded into a Claude session (which happened during this trial).

## Next week's carousel, in five steps

1. Copy `jobs.json` and write a new cover scene. Keep `P_REF`, `P_DAY`, `P_NIGHT` and `NO_TEXT`. A different child per carousel is fine (the user's choice): write a new character description and generate one reference photo first.
2. Check the reference at full size (face, hands, objects), then generate the other slides from it.
3. Inspect every image at full size: hands, legs, faces, objects, any lettering, and any hard edge inside the picture. In this trial one illustrated image had an extra leg, and one photo had a flat slab pasted over the sky.
4. Paste the new copy into `carousel.html` and adjust `PUSH` in `prep_art.py` if a head reaches the text.
5. Export, then check `contact-sheet.png` and `source/qa-25pct.png`.

## Design system

| Element | Rule |
|---|---|
| Canvas | 1080×1350. Side margins 92px, top 84px, bottom 92px. The side margins leave room for Instagram's profile-grid crop (exact crop not measured in this trial) |
| Beats | Slides 1 to 5 are daylight on warm cream; slides 6 and 7 are a dim violet evening (night `#0B0518` ground, cream type), so the story world and the CTA feel like a different place |
| Colour | Ink `#1D1039` for type, gold `#B07C2E` (`#E6B762` on dark) for the thread and emphasis, cream `#F3EADC` ground. Derived from the lumebook.com tokens in `sites/lumebook-ambassadors/index.html` (ink `#1D1039`, gold `#C9954A` / `#E6B762`, cream `#F8F0E1`); the gold is darkened for contrast on cream |
| Type | Two families. Rubik 700 for headlines (92px on slides 1, 4, 5; 84px on 3; 78px on 2; 76px on 6; 70px on 7), Assistant for the CTA line and meta text. No small labels above the headlines (removed at the user's request) |
| Text zone | Right-aligned, RTL, starting at y=206 on every slide. Image prompts reserve the top 45% as plain wall (`P_DAY`, `P_NIGHT`); `PUSH` gives extra room on slides 1, 2, 3 and 6 |
| Motif | One gold thread, 5.5px, at y=148 on both edges of every slide so a swipe follows one unbroken line, with a round bead at each knot. Its shape tells the beat: a loose end (1), a loop (2), two strands (3), a knot (4), slack (5), a rise (6). On slide 7 it ends in a ribbon bookmark: he keeps his place |
| Progress | `n/7` top left; the LumeBook wordmark top right on every slide |
| Swipe cue | Slide 1 only: a cream pill "החליקו ←" bottom left |
| Product | First seen on slide 6 (he finds himself inside a book), named only on slide 7 |
| CTA | Slide 7: "צרו תצוגה מקדימה בחינם", the one call to action in `docs/lumebook-social-strategy.html`, then the book's name and where to click |
| AI disclosure | "נוצר בעזרת AI" on slide 1 and "התמונות נוצרו בעזרת AI" on slide 7, in line with the playbook's rule to label AI scenes. Also say it in the caption and use Instagram's AI label, because these look like real photographs |

The logo in `sites/lumebook-ambassadors/img/logo_square.png` is authorised, but its bright cartoon mascot fights this look, so the slides use a text wordmark.
