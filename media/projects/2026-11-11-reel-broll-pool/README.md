## The library (11 Nov 2026)

Yarin: "name everything you create/generate and save it with the rest so you can always reuse it to save api cost". `library.json` lists every file here (and the store covers and the wizard recording where they live) with what it shows, the Hebrew words it fits, how it was made (the GPT scene and prompt, or the drawing spec), what it cost and the reels that use it. `library.py` in the series folder reads and writes it (`library.py list [kind]`, `library.py check`). The calendar's make job shows the planner this list, so a reel job can use any file here by its name (`pool:gpt/...png`); the server links it into the reel.
