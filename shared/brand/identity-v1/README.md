# LumeBook identity v1 (proposed)

Copied on 17 / 11 / 2026 from the brand kit `lumebook-brand-v1` (Yarin's Downloads folder, made the same day). A proposed identity: a purple 3D wizard hat with one centered yellow star and a Heebo 900 wordmark. Rules: `brand-guidelines.md` (the PDF version stays in the kit); exact colours: `web/design-tokens.json`.

Only the files the site work uses are here: logos (flat vectors, wordmarks, the 3D hat and PNG lockups), web tokens, CSS, icons, favicons, guidelines, contrast checks and the Heebo variable font with its licence. Left in the kit: `brand-guide.pdf` (11 MB, same text as the .md), `app-icon.svg` and the SVG lockups that embed the 3D hat as a 1.8 MB raster, social templates, print artwork and the mockups.

Do not use the kit's hero and product scenes (`02-web/hero-*`, `06-mockups/*`) as product pictures: the kit itself says they are concepts, not photos of real books, albums or packaging.

Used by: `sites/lumebook-home-redesign` (logo, colours, type weights, radii, icons, favicon).
