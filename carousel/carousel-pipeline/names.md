# Child names

Every carousel option is about one named child: an Israeli girl or boy who talks to mom or to both parents, never to dad (Yarin, 7 Oct 2026). The validator only accepts names from this list, matched to the option's `child_gender`, and each option in a pack uses a different name. `nightly.py start` lists names used in the last 7 packs so the writer rotates.

Add names by adding them to the right row, separated by `·`. Leave out names that appear in LumeBook catalogue titles (נוי, עמית, אלי, יובל, עדן in `docs/lumebook-product-brief.md`), so a name never hints at a specific book.

## How the name is used

- Put the name where a real family would say it, usually inside a quoted sentence from mom ("״נועם אחרי המנוחה אני כאן״") or in the hook ("נועם בן 3 שוב בוכה בשער")
- It must appear at least once on the slides before the last one
- The same name keeps the same gender, age and look as the option's character anchor
