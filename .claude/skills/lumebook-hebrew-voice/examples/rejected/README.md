# Rejected or edited copy

Copy Yarin rejected or rewrote, with the reason. These teach the writer what to avoid. They never count toward calibration.

File name: `NNN-short-context.md`

Template:

```markdown
---
source: nightly pack 2026-10-08 expert-2 slide 4
reason: too polished, sounds like a therapist
yarin_version: optional, the line as Yarin rewrote it
---

<the rejected text>
```

Typical reasons: too polished, too corporate, therapist voice, translated from English, too cute, guilt, promise, not how I speak.

Lines Yarin rewrote on the review page are already logged automatically in `../edits.jsonl` (the `before` side). Use this folder for copy rejected elsewhere, with the reason.
