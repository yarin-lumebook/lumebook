# Self review rubric

Run this after drafting and before the lint. Each question is yes or no. Any "no" means rewrite that line.

1. Read aloud: does every line sound like something a person says, not writes?
2. Would an Israeli parent say these exact words, or is it a translation of an English idea?
3. Is the narrator consistent (the child stays a child, the expert stays plain and calm)?
4. One thought per line, and each slide has one idea?
5. Can someone who reads only the headlines follow the story?
6. Is every feeling stated as possible, not universal ("הרבה ילדים", not "כל ילד")?
7. Is there any word a parent would need to look up?
8. Is there any line that blames the parent or tries to scare them?
9. Does any factual line lack a source in the claims list?
10. Does the product line promise an outcome (fixes, treats, guarantees)? It must not
11. Is there exactly one CTA, word for word the same on the last slide and the caption's last line?
12. No em dash, period or comma anywhere a parent will read it?
